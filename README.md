# Proyecto Final - Sistemas Operacionales

## Herramienta de Administración para Data Center

Este proyecto corresponde al proyecto final del curso de Sistemas Operacionales de la Universidad Icesi.

El objetivo principal es desarrollar dos herramientas de administración, una en **PowerShell** y otra en **Bash**, que permitan realizar tareas básicas de monitoreo y mantenimiento sobre una máquina local, simulando labores comunes de un administrador de un data center.

Las herramientas funcionan mediante un menú interactivo en consola y permiten consultar usuarios, discos o filesystems, archivos de gran tamaño, memoria disponible, uso de swap o pagefile, y realizar copias de seguridad hacia una memoria USB.
